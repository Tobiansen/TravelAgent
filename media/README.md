# Images

## Hardware

The README gallery follows the build from electronics to CAD to the assembled device:

1. [Atech layout](hardware/01-atech-layout.jpg): the confirmed electrical port layout rendered in Atech's official SDK board viewer. The real drum motor is mounted separately and connected by wires.
2. [Fusion design](hardware/02-fusion-design.png): the team's supplied enclosure and drum assembly screenshot.
3. [Built device](hardware/03-built-device.jpg): the team's supplied photograph. Location metadata was removed; pixels, orientation and color profile are unchanged.

Atech module models by [Atech](https://atech.dev/), licensed under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), appear in the Atech and Fusion images. The TravelAgent team positioned and rendered the reference models; see the [model source and notice](https://github.com/atechdotdev/atech-atelier/blob/main/models/LICENSE.md).
